## 目标
工具层从离线 10 城 JSON 改为**在线高德地图 Web 服务 API**,新增**输入即搜索**(如"找成都免费景点"直接出结果)与**找免费**;**高德免费配额每日限额,超出后整个程序停止**;删除离线城市数据,保留通用兜底用于非配额故障(网络/限流/超时)。

## 已确认事实(真实 API 探测)
- Key `5802...1034` 有效;景点(风景名胜)有 `biz_ext.rating` 但**无门票价**;`type` 三级分类 + `keytag` 可判免费倾向;`adname`=行政区
- 餐厅(餐饮服务)有 `biz_ext.cost`=人均、`biz_ext.rating`
- 酒店(住宿服务)`lowest_price`/`cost` 为空 → 档位启发式估算
- 天气:`/v3/weather/weatherInfo?city=adcode&extensions=all` 4 天预报;adcode 由 `/v3/geocode/geo` 获取;参数 `keywords`/`types` 二选一;限流码 10003/10004

## 价格/免费策略(估算,文档明示)
- 餐厅:用 `biz_ext.cost`,缺失默认 60
- 酒店:keytag/名称→档位,价格=档位区间中点(225/450/900),tag"价格估计"
- 景点:免费倾向词表(公园/广场/博物馆/街区/步行街等)→price=0 且 tag"免费";付费倾向(动物园/水上乐园/景区等)→词表估算价;"找免费"按免费倾向过滤
- 预留高德门票服务市场 API 扩展点

## ★ 免费配额机制(本次新增)
- **按服务每日计数**:search(place/text)、geocode、weather 三个计数器,写入项目根 `.amap_quota.json`(加入 .gitignore),跨进程持久化;日期变化自动清零
- **配置**(env 可调,默认保守):`AMAP_DAILY_LIMIT_SEARCH=3000`、`AMAP_DAILY_LIMIT_GEOCODE=1000`、`AMAP_DAILY_LIMIT_WEATHER=1000`
- **超限行为**:AmapClient 每次请求前 `quota.check()`,任一服务超限 → 抛 `QuotaExhaustedError`;**InfoAgent 特判该异常不兜底、直接上抛**;启动时 main.py 先查配额文件,已耗尽 → 打印提示并**退出程序**(exit 3):"高德免费配额已用完,请明天再试或在 .env 调整 AMAP_DAILY_LIMIT_*";调用过程中超限 → 中断当前规划,同样提示退出
- 附带轻量节流:两次高德调用间隔 ≥400ms,防个人 Key QPS(3)触发限流,也避免误撞配额
- 非配额故障(网络/超时/QPS 限流)仍走"超时→重试 1 次→通用兜底",流程不中断

## 风险与说明
- 门票价/酒店价为分类估算(API 无真实价格字段),结果标注"估算"
- 天气仅 4 天预报,5~7 天行程复用末日天气
- 配额默认值需与你的 Key 实际免费档位一致(可在 .env 调整)
